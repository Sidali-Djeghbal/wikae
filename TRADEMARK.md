# Wikae name and logo

Wikae (وِكَاء), its wordmark and its logos are the names and branding of this fork, maintained by Sidali Djeghbal. The code is AGPL-3.0; this page is about the name and logo, not the code license.

Wikae is a separate fork and rebrand of Étude. The "Étude" name, the ε logo and the etude.study domain belong to João Henrique Costa Araujo and are not covered by the AGPL-3.0 code license. Wikae does not claim them.

You can:

- say that Wikae is based on Étude or forked from Étude;
- use the Wikae name and logo to talk about Wikae itself (articles, videos, reviews, tutorials);
- keep using the name and logo in an unmodified copy you run for yourself.

You need written permission (contact@djeghbal.me) to:

- publish a modified version, fork or hosted service under a name or logo that could be confused with Wikae;
- sell anything under the Wikae name or logo.

If you fork Wikae, give it a different name and logo, and keep your own project's branding and links distinct from Wikae's. The Wikae website is https://sidali-djeghbal.github.io/wikae.
